# AGREED DESIGN
Two assessment levels on two independent axes:
1. WHICH controls: `standard` = a human-selected minimum-security subset; `pro` = additional/stricter controls.
2. HOW DEEP: Standard checks mostly verify presence/absence of required configuration (running-config only). Pro checks verify HOW and WHERE it is applied (interfaces, VLANs, conditions) and may need more evidence and interface roles.
One rule can carry both depths. Output is a table with a Standard column (minimum security) and a Pro column (recommendations to raise security). The overall "minimum security" verdict is derived ONLY from the Standard column. A Standard PASS means "required configuration is present", never "control is fully effective".
